# Jarvis Cognitive Lab Web

Interface móvel para executar e observar experimentos cognitivos sem depender de um PC local.

A V1 é um laboratório determinístico de observação funcional. Ela não afirma consciência e não expõe cadeia de pensamento privada. Próximas versões devem conectar a UI ao Cognitive Engine real via API autenticada.

Para publicação estática, use esta pasta como root de um projeto Vercel/Static Host.
