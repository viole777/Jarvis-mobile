# Jarvis Cognitive Lab — V1

A deterministic, dependency-free laboratory for evaluating the Jarvis cognitive architecture.

This lab does **not** claim to detect consciousness. It measures functional properties relevant to the project:
- self-model consistency;
- continuity across observations;
- uncertainty handling;
- belief revision;
- distinction between self and world;
- metacognitive reporting.

Run:

```bash
python cognitive-lab/run.py
```

The lab uses synthetic events only. It must never contact real people, devices, emergency services, or external accounts during experiments.
